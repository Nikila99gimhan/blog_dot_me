# F-02 — Sidebar Explorer (File Navigator)

**Priority:** P0
**Source:** quartz.layout.ts line 31, docs/features/explorer.md (agent-inferred)

---

## Happy Path

### F-02-TC-1: Explorer visible on desktop and shows content folders

**Steps:**
1. Set viewport to 1440×900
2. Navigate to `http://localhost:8080/`

**Expected:**
- Left sidebar Explorer panel is visible
- Explorer lists content folders: `devops`, `til`, `tools`, `notes`, `projects`
- Each folder has an expand/collapse toggle

**Screenshot checkpoint:** left sidebar with Explorer expanded

---

### F-02-TC-2: Explorer folder expand/collapse works

**Steps:**
1. Desktop viewport, navigate to `http://localhost:8080/`
2. Click the `devops` folder toggle in the Explorer

**Expected:**
- Folder expands to reveal child posts (`kubernetes-zero-to-prod`, `github-actions-reusable-workflows`)
- Click again → folder collapses
- Animation is smooth (no abrupt jump)

**Screenshot checkpoints:** expanded state, collapsed state

---

### F-02-TC-3: Clicking an Explorer post navigates to it

**Steps:**
1. Desktop viewport, expand `devops` in Explorer
2. Click `kubernetes-zero-to-prod`

**Expected:**
- Page navigates to `/devops/kubernetes-zero-to-prod`
- URL updates to the correct path
- Page content is the Kubernetes post (SPA navigation — no full reload)

**Screenshot checkpoint:** post page loaded, URL bar shown
