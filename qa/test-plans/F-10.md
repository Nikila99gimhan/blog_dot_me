## Happy Path

### F-10-TC-1: Tag page renders for a known tag

**Steps:**
1. Navigate to `http://localhost:8080/tags/kubernetes`

**Expected:**
- Page renders with title "kubernetes" or "Tag: kubernetes"
- "Kubernetes: Zero to Prod" post appears in the listing
- Each listing entry shows post title and date
- Page uses the list page layout (Breadcrumbs, ArticleTitle, ContentMeta; no TOC in right sidebar)

**Screenshot checkpoint:** kubernetes tag page with post listing

---

### F-10-TC-2: Tags index page renders with all tags

**Steps:**
1. Navigate to `http://localhost:8080/tags/`

**Expected:**
- Page renders listing all available tags
- Tags include: kubernetes, devops, containers, k8s, github-actions, cicd, automation
- Each tag entry links to its individual tag page

**Screenshot checkpoint:** tags index page

---

### F-10-TC-3: Clicking a tag from a post navigates to the tag page

**Steps:**
1. Navigate to `/devops/kubernetes-zero-to-prod`
2. Click the "devops" tag pill in the TagList component

**Expected:**
- Browser navigates to `/tags/devops`
- Tag page renders with all posts tagged "devops"
- Both kubernetes and github-actions posts appear (both have `devops` tag)

**Screenshot checkpoint:** devops tag page with 2 posts listed

---

### F-10-TC-4: Folder listing page renders for devops section

**Steps:**
1. Navigate to `http://localhost:8080/devops`

**Expected:**
- Page renders as a folder/section listing
- Lists all posts in the devops folder: `kubernetes-zero-to-prod`, `github-actions-reusable-workflows`
- Each entry shows title and date
- Breadcrumbs show "Home > devops"

**Screenshot checkpoint:** devops folder listing
