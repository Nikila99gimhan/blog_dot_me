## Happy Path

### F-08-TC-1: Graph view panel is accessible from a content page

**Steps:**
1. Desktop viewport (1440×900)
2. Navigate to `/devops/kubernetes-zero-to-prod`
3. Look for a graph view button, panel, or footer link

**Expected:**
- A graph view toggle or panel is visible somewhere on the page
- Clicking it opens the graph view

**If NOT found:** Mark as BLOCKED — GAP-05 (not in quartz.layout.ts)

**Screenshot checkpoint:** graph panel visible (or note of absence)

---

### F-08-TC-2: Graph renders with current page as highlighted node

**Steps:**
1. Open graph view for `/devops/kubernetes-zero-to-prod`

**Expected:**
- Graph canvas is rendered (D3 SVG or canvas element)
- Current page node (`kubernetes-zero-to-prod`) is highlighted (different color, larger)
- Connected nodes are visible (at minimum: `github-actions-reusable-workflows` via wikilink)
- No console errors during graph render

**Screenshot checkpoint:** graph with current node highlighted and edges visible

---

### F-08-TC-3: Clicking a graph node navigates to that note

**Steps:**
1. Open graph view
2. Click on the `github-actions-reusable-workflows` node

**Expected:**
- Page navigates to `/devops/github-actions-reusable-workflows`
- Graph view closes or updates to show new page's graph

**Screenshot checkpoint:** after navigation from graph click

---

## Edge Cases

### F-08-TC-4: Graph renders on a page with no outgoing links

**Steps:**
1. If such a page exists (e.g., homepage or a simple TIL post), open graph view

**Expected:**
- Graph renders with only the current page node (no edges)
- "Isolated" node is still shown — not an empty canvas
- No errors

**Screenshot checkpoint:** isolated node graph

---

### F-08-TC-5: Graph is interactive (nodes are draggable or hoverable)

**Steps:**
1. Open graph view for any content page
2. Hover over a node

**Expected:**
- Hover state shows node label or title clearly
- If draggable: nodes can be repositioned without errors

**Screenshot checkpoint:** hovered node state

---

## Negative Cases

### F-08-TC-6: Graph does not make external network requests for node data

**Steps:**
1. Open graph view
2. Monitor Network tab for unexpected external requests

**Expected:**
- All graph data is served from localhost:8080
- No calls to external APIs or CDNs for graph data
- Graph functions fully offline (except Google Fonts CDN for typography)
