# F-11 — Popover Previews

**Priority:** P1
**Source:** quartz.config.ts (enablePopovers: true), docs/features/popover previews.md (agent-inferred)

---

## Happy Path

### F-11-TC-1: Hovering an internal wikilink shows a popover preview

**Steps:**
1. Desktop viewport (1440×900)
2. Navigate to `/devops/kubernetes-zero-to-prod`
3. Scroll to "What's Next?" section (line 214: `[[devops/github-actions-reusable-workflows|CI/CD with GitHub Actions]]`)
4. Hover over the internal link

**Expected:**
- A popover/tooltip appears after a short delay (not instant)
- Popover shows the title of the linked page: "GitHub Actions Reusable Workflows"
- Popover shows a brief excerpt or description of the linked page
- Popover does not overlap current reading content in a disruptive way

**Screenshot checkpoint:** popover visible over internal link

---

### F-11-TC-2: Popover disappears when mouse leaves

**Steps:**
1. Hover over an internal link to trigger popover
2. Move mouse away from the link

**Expected:**
- Popover closes/fades out when mouse leaves
- No lingering popover after mouse has moved away
- No layout shift after popover closes

**Screenshot checkpoints:** popover open, then closed after mouse exit

---

### F-11-TC-3: Popover loads lazily (content fetched on hover)

**Steps:**
1. Open browser DevTools Network tab
2. Hover over an internal wikilink

**Expected:**
- A network request is made to fetch the linked page's preview content on hover
- Request goes to `localhost:8080/devops/github-actions-reusable-workflows` (or similar)
- Popover shows content once loaded (may have a brief loading state)

**Screenshot checkpoint:** popover with content loaded

---

## Edge Cases

### F-11-TC-4: External links do NOT trigger popovers

**Steps:**
1. Navigate to `/devops/kubernetes-zero-to-prod`
2. Hover over an external link (e.g., any `https://` link in the content)

**Expected:**
- No popover appears for external links
- Standard browser link behavior only (cursor change, status bar URL)

**Screenshot checkpoint:** hovering external link — no popover

---

### F-11-TC-5: Popover works for links across different content sections

**Steps:**
1. Navigate to `/devops/github-actions-reusable-workflows`
2. Hover over `[[devops/kubernetes-zero-to-prod|Kubernetes: Zero to Prod]]` link

**Expected:**
- Popover shows "Kubernetes: Zero to Prod" preview
- Content loads correctly

**Screenshot checkpoint:** cross-section popover

---

## Negative Cases

### F-11-TC-6: Popover for a page with no description renders gracefully

**Steps:**
1. Identify a page with no `description` frontmatter field
2. Hover over a wikilink to that page

**Expected:**
- Popover renders with at minimum the page title
- If description is missing, either empty description area or first paragraph of content
- No JavaScript error from missing description field

---

### F-11-TC-7: Rapid hover-unhover does not cause multiple concurrent popovers

**Steps:**
1. Hover over a link, then quickly move to another link, then another

**Expected:**
- Only one popover is visible at a time
- Previous popovers are dismissed before new ones appear
- No visual stacking of multiple popovers

**Screenshot checkpoint:** single popover at a time
