## Happy Path

### F-06-TC-1: Bash code blocks are syntax-highlighted in dark mode

**Steps:**
1. Enable dark mode
2. Navigate to `/devops/kubernetes-zero-to-prod`
3. Inspect the first `bash` code block

**Expected:**
- Code is NOT rendered as plain black/white text
- Tokens are colored (commands in one color, flags in another, etc.)
- Background of code block is the One Dark Pro dark grey (not site background)
- `keepBackground: true` means the code block has its own distinct background

**Screenshot checkpoint:** bash code block in dark mode with syntax colors
