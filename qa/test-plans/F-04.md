# F-04 — Dark / Light Mode Toggle

**Priority:** P0
**Source:** quartz.config.ts (colors block), quartz.layout.ts line 30, docs/features/darkmode.md (agent-inferred)

---

## Happy Path

### F-04-TC-1: Dark mode toggle button is visible and interactive

**Steps:**
1. Desktop viewport (1440×900), navigate to `http://localhost:8080/`

**Expected:**
- Darkmode toggle button is visible in the left sidebar
- Button has a sun or moon icon (or similar visual indicator)
- Button is clickable

**Screenshot checkpoint:** sidebar with darkmode toggle visible

---

### F-04-TC-2: Toggling dark mode switches the color scheme

**Steps:**
1. Navigate to homepage
2. Note current mode (check background color)
3. Click the Darkmode toggle button

**Expected:**
- Page background switches theme
- Dark mode: background is `#0d0f14`, accent color is `#39ff14` (neon green)
- Light mode: background is `#f4f4f0`, accent color is `#2d6a4f` (forest green)
- Toggle switch is immediate (no full reload)

**Screenshot checkpoints:** before toggle (light), after toggle (dark)

---

### F-04-TC-3: Dark mode preference persists across page navigation

**Steps:**
1. Enable dark mode
2. Click a post link to navigate to a different page (via SPA)

**Expected:**
- Dark mode remains active on the new page
- No flash of light mode during navigation

**Screenshot checkpoint:** post page in dark mode

---

### F-04-TC-4: Dark mode preference persists across browser reload

**Steps:**
1. Enable dark mode
2. Press `Ctrl+R` / `Cmd+R` to reload the page

**Expected:**
- Page reloads in dark mode (localStorage preference respected)
- No flash of light mode on initial load

**Screenshot checkpoint:** page after reload, dark mode active

---

## Edge Cases

### F-04-TC-5: System preference (prefers-color-scheme) is respected on first visit

**Steps:**
1. Clear localStorage and browser cookies
2. If OS is set to dark mode, navigate to `http://localhost:8080/`

**Expected:**
- Site launches in dark mode automatically
- No manual toggle required

**Note:** This test is environment-dependent. If OS is in light mode, verify light mode is the default.

**Screenshot checkpoint:** first visit with clean localStorage

---

### F-04-TC-6: Toggle works on mobile viewport

**Steps:**
1. Set viewport to 375×812
2. Navigate to homepage
3. Locate and click the Darkmode toggle

**Expected:**
- Toggle is accessible on mobile
- Theme switches correctly on mobile

**Screenshot checkpoint:** mobile in dark mode

---

## Negative Cases

### F-04-TC-7: Rapid toggling does not cause visual glitches

**Steps:**
1. Click darkmode toggle rapidly 5 times in a row

**Expected:**
- Final state matches the expected toggle position (odd clicks = dark, even = light, or vice versa)
- No CSS transition artifacts or stuck intermediate states
- No console errors

**Screenshot checkpoint:** state after rapid toggling
