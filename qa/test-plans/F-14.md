# F-14 — SPA Routing (Client-Side Navigation)

**Source:** quartz.config.ts (enableSPA: true), package.json (micromorph dependency) (agent-inferred)

## Happy Path

### F-14-TC-1: Navigation between pages does not trigger a full browser reload

**Steps:**
1. Desktop viewport (1440×900)
2. Navigate to `http://localhost:8080/`
3. Open browser DevTools → Network tab → check "Preserve log"
4. Click "Kubernetes: Zero to Prod" from Recent Posts

**Expected:**
- Browser does NOT perform a full page reload (no full document request in network)
- Only partial content/resource requests are made (JS, JSON, etc.)
- The page transition is smooth (no white flash between pages)
- URL changes to `/devops/kubernetes-zero-to-prod`

**Screenshot checkpoint:** Network tab showing SPA fetch (not full reload), new page content visible

---

### F-14-TC-2: Browser back button works after SPA navigation

**Steps:**
1. Start at homepage
2. Click a post link (SPA navigation)
3. Click another post link (second SPA navigation)
4. Press browser back button

**Expected:**
- Returns to the previous post page
- URL reflects previous page
- Content is correct (not the homepage or a wrong page)

**Screenshot checkpoints:** after forward navigation, after back navigation

---

### F-14-TC-3: Browser forward button works after going back

**Steps:**
1. Navigate forward twice (homepage → post A → post B)
2. Go back twice (to homepage)
3. Press browser forward button

**Expected:**
- Goes forward to post A
- Then can go forward again to post B
- History is correctly maintained

---

### F-14-TC-4: Page URL is correct and shareable after SPA navigation

**Steps:**
1. Navigate to a post via SPA
2. Copy the URL from the address bar
3. Paste into a new tab (simulating sharing)

**Expected:**
- URL in new tab loads the post directly (SSR/static files serve it correctly)
- Page renders with the same content

- Active item is updated to current post

**Screenshot checkpoint:** sidebar state preserved after SPA navigation

### F-14-TC-6: Dark mode state is preserved across SPA navigation
