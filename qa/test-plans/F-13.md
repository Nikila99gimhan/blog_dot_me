## Happy Path

### F-13-TC-1: Breadcrumbs appear on a nested content page

**Steps:**
1. Desktop viewport (1440×900)
2. Navigate to `/devops/kubernetes-zero-to-prod`

**Expected:**
- Breadcrumb trail is visible above the article title
- Breadcrumb shows: `Home > devops > Kubernetes: Zero to Prod` (or similar hierarchy)
- Each segment is a clickable link (except possibly the current page)

**Screenshot checkpoint:** breadcrumb trail above article title

---

### F-13-TC-2: Clicking a breadcrumb segment navigates correctly

**Steps:**
1. Navigate to `/devops/kubernetes-zero-to-prod`
2. Click "devops" in the breadcrumb trail

**Expected:**
- Page navigates to `/devops` folder listing
- Breadcrumbs update to reflect new page context

**Screenshot checkpoint:** devops folder page after breadcrumb navigation
