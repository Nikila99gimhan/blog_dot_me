# nikila.dev - DevOps & Homelab Blog

A terminal-inspired, minimal digital garden and technical blog focusing on DevOps, Kubernetes, and Platform Engineering.

Built using [Quartz v4](https://quartz.jzhao.xyz/).

## Features
- Deep technical dives and homelab architecture notes
- Custom dark mode terminal theme
- Copy-paste ready code blocks
- Fully static, extremely fast

## Development
To run locally:
```bash
npx quartz build --serve --port 8080
```
